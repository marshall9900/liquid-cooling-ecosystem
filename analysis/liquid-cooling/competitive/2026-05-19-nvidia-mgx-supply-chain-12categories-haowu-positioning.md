### 2.2 海悟未进入 MGX 供应链的原因分析

| 原因 | 分析 |
|------|------|
| **认证周期 12-18 月** | NVIDIA Cold Plate 认证是供应链最高壁垒之一 |
| **NPN (NVIDIA Partner Network) 体系** | 英维克是大陆唯一 NPN Tier1，海悟未进入 |
| **TW 供应链绑定** | 双鸿/奇宏/台达/光宝等占据 60%+产能，先发优势巨大 |
| **MGX 是 NVIDIA 私有生态** | 与华为/中兴/百度国产超节点生态系统有本质区别 |

## 三、海悟战略路径选择

### Path A: 攻坚 NVIDIA MGX（需 12-18 个月 + NPN 认证）
- ❌ 认证周期长（意味着 2027+ 才能供货）
- ❌ 英维克已深度卡位（大陆 Tier1 唯一）
- ❌ TW 供应链先发优势巨大
- ⚠️ 可从小品类（管路/冷板）尝试，但竞争激烈

### 🔥 Path B: 主攻国产超节点（推荐）
| 对象 | 优势 | 优先级 |
|------|------|--------|
| **中兴 Nebula** | 开放 OEX/不做液冷/ODCC 标准 | 🔥🔥🔥 P0 |
| **百度天池 512** | 门槛最低/2026H2/CDU 自研（海悟做冷板+接头） | 🔥🔥 P1 |
| **阿里磐久 128** | 通过阿里自有测试 | 🔥 P2 |
| **华为 Atlas 950** | 华为认证体系 | P3 |

### Path C: 差异化切入新品类
- 浸没液冷（NVIDIA 尚未认证，国内国标缺失 → 海悟有机会定义标准）
- 硅基微通道冷板（中兴白皮书明确看好，前瞻布局）
- 800V HVDC 液冷配套（电力电子 + 液冷协同）

## 五、对海悟战略的修正建议

1. **不把 NVIDIA MGX 作为主攻方向** — 竞争过于拥挤，认证周期过长
2. **国产超节点是主战场** — 中兴 Nebula（最开放）→百度天池（门槛最低）→阿里磐久
3. **液冷管路可作为进入 MGX 生态的"敲门砖"** — 与川环科技差异化竞争（中低压 vs 高压）
4. **浸没液冷 + 硅基微通道冷板** — 前瞻布局，在 NVIDIA 未来认证中抢占先机
5. **跟踪英维克动态** — 作为大陆唯一 Tier1，其产能扩张/订单节奏是行业风向标
