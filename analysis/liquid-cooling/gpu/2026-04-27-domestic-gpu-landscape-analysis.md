| 出货量预测 | 基于算力需求推演模型 | ⭐⭐ 估算 |

### 1.2 估算方法

- **出货量预测**：基于中国智算中心建设节奏（2026-2030年智能算力从~300 EFLOPS增长到~1500 EFLOPS，CAGR ~38%）、国产化率目标（🆕 2026年已>70%→2027年80-90%→2030年90%+，比此前预估大幅提前）、以及各GPU厂商市场份额推算
- **液冷渗透率**：基于TDP阈值模型：<200W→全风冷；200-350W→冷板/风冷可选；350-500W→冷板主导；>500W→冷板必需+浸没可选
- **快接头需求**：每冷板GPU卡需2个快接头（进口/出口），冷板方案中每卡需1个冷板

### 1.3 关键假设

> ⚠️ 本文所有2027-2030年数据均为基于趋势外推和专业判断的估算值（E），非实际披露数据。实际值可能因政策、供应链、技术突破等因素产生重大偏离。
> 
> 🆕 **2026年5月刷新说明**：本文基于2026年5月获取的字节跳动芯片专家纪要和中国IDC圈行业访谈进行数据刷新。关键变化包括：1）国产化率曲线大幅提前（2027年目标80-90%而非此前预估的50%）；2）寒武纪690批量交付确认；3）字节自研芯片三星6nm流片确认；4）腾讯昆仑芯30万张订单确认。上述数据均标注来源。

## 附录B：估算模型说明

### 出货量预测模型

```
出货量(E) = 中国智算中心智能算力总需求(f) × 
             NPU/GPU占算力比例 × 
             国产化率 × 
             厂商市占率 ÷ 
             单卡FP16算力 × 
             利用率系数
```

关键假设：
- 2026年中国智能算力 ~300 EFLOPS → 2030E ~1500 EFLOPS（CAGR ~38%）
- 国产化率：2026E 40% → 2028E 55% → 2030E 65%
- 单卡等效FP16算力：2026E ~300 TFLOPS → 2030E ~800 TFLOPS（制程+架构进步）

### 液冷渗透率模型

```
液冷渗透率 = f(TDP, 部署密度, 行业接受度)
           = 0% (TDP < 200W)
           = 10-30% (TDP 200-350W)
           = 50-70% (TDP 350-500W)
           = 80-95% (TDP > 500W)
```
