## 一、OTT决策链

### 1.1 阿里
| 维度 | 内容 |
|------|------|
| 组织架构 | 阿里云智能→基础设施事业部→DC与服务器团队→热管理/液冷组 |
| 关键角色 | CTO(吴翰清?阿里云CTO)→Infra VP→DC Director→热管理工程师 |
| 预算来源 | 阿里集团Capex→阿里云→基础设施事业部 |
| 采购模式 | 阿里液冷认证体系(自研)→招标 |
| 准入流程 | 送样→阿里自有测试(3-9月)→小批量试点→框架协议→量产 |
| 关键影响者 | 热管理工程师团队(技术评估)、阿里云CTO(战略决策) |
| 决策周期 | 首次准入 9-18个月 |
| 供应商策略 | 多供应商(2-3家同步) |
| 替换成本 | 中(阿里认证重跑但不如Intel困难) |
| 认证要求 | 🔥阿里自有液冷认证体系 |

## 二、OEM决策链

### 2.1 H3C (新华三)
| 维度 | 内容 |
|------|------|
| 组织架构 | 服务器产品线→硬件工程→散热/液冷组→供应链采购 |
| 关键角色 | 服务器产品VP→硬件工程总监→液冷工程师→采购经理 |
| 预算 | 按项目/客户(阿里→阿里项目预算，字节→字节项目) |
| 采购模式 | 白牌代工模式：**OTT客户可能指定液冷供应商** 或 H3C推荐 |
| 准入流程 | 供应商认证→送样→H3C内部测试(1-3月)→客户确认→小批量 |
| 决策周期 | 3-6月(首次) |
| 供应商策略 | 多供应商(2-3家) |
| 替换成本 | 低-中（H3C本身认证简单，但OTT客户可能锁定供应商） |
| 🔥关键洞察 | H3C是白牌OEM，液冷决策受OTT客户影响大。**如果阿里/字节指定某液冷供应商，H3C必须用。** 反过来也可通过H3C推荐进入OTT。 |

### 2.2 浪潮
| 维度 | 内容 |
|------|------|
| 组织架构 | AI服务器事业部→硬件研发→散热组→供应链 |
| 关键角色 | AI服务器VP→研发总监→散热主任工程师→采购总监 |
| 预算 | 按项目+年度框架 |
| 采购模式 | 供应商准入→招标→框架协议→按MI单执行 |
| 准入 | 供应商注册→技术评审→送样测试→商务谈判→框架协议 |
| 决策周期 | 6-9月 |
| 供应商策略 | 多供应商(通常2-3家) |
| 替换成本 | 中(框架协议下更换需重新测试+商务) |

### 2.3 Dell / Supermicro（海外线参考）
| 维度 | Dell | Supermicro |
|------|------|-----------|
| 液冷供应商策略 | 认证供应商 | 自有+认证 |
| 准入 | Intel UQD+NVIDIA | Intel UQD+NVIDIA |
| 海悟机会 | 远期(双认证后) | 远期 |

## 三、GPU公司认证链路

### 3.1 NVIDIA Cold Plate认证
| 维度 | 内容 |
|------|------|
| 谁管 | NVIDIA Data Center Engineering → Thermal/Cooling组 |
| 流程 | 提交申请→技术审查→送样→NVIDIA热测试→可靠性测试→批准→列入Approved Vendor List |
| 周期 | 6-9月 |
| 通过后 | 可供货所有Blackwell(NVL72/NVL36/HGX)冷板 |
| 🔥价值 | 列入AVL = 全球OEM/ODM都可以采购你的冷板用于NVIDIA方案 |

### 3.2 华为Atlas认证
| 维度 | 内容 |
|------|------|
| 谁管 | 华为Ascend/AI计算产品线→液冷生态组 |
| 流程 | 华为认证申请→技术评审→送样→华为热测试→兼容性测试→列入华为认证供应商 |
| 周期 | 6-12月 |
| 通过后 | 可供货Atlas 900/Atlas新超节点液冷组件 |
| 🔥价值 | 进入华为昇腾生态 = 覆盖运营商+政务+华为系OTT |

## 四、决策链关键发现

| 客户 | 开放性 | 决策周期 | 海悟最佳进入方式 | 优先级 |
|------|--------|---------|----------------|--------|
| **H3C** | ⚠️半开放(受OTT影响) | 3-6月 | 直接送样+通过阿里/字节项目切入 | 🔴P0 |
| **浪潮** | ⚠️半开放 | 6-9月 | 送样测试→框架协议 | 🔴P0 |
| **阿里** | 阿里认证 | 9-18月 | 先通过H3C间接进入→再申阿里直接认证 | 🟠P1 |
| **字节** | 字节测试 | 6-12月 | 通过H3C/秦淮→再申字节直接认证 | 🟠P1 |
| **腾讯** | 招标 | 6-12月 | 送样→测试→招标 | 🟠P1 |
| **华为** | 华为认证 | 6-12月 | 申华为Atlas认证 | 🟡P2 |
| **NVIDIA** | NVIDIA认证 | 6-9月 | 申NVIDIA Cold Plate认证 | 🟡P2 |
| **Meta(海外)** | OCP | 3-6月 | 先过OCP→再通过Dell/Supermicro进入 | P2海外 |

> 🔥 **最现实路径**：先攻H3C+浪潮(国内OEM，决策周期短)→再借H3C渠道进入阿里/字节→同步申请华为/NVIDIA认证。
