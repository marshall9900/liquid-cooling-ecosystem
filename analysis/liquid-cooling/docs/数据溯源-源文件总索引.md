## 铁律⑤执行规则

1. **源文件刷新 → 扫描本索引 → 找出受影响的分析文件 → 刷新分析**
2. **同一指标多源冲突 → 以发布时间最新的源文件为准**
3. **每次分析更新后 → 在分析文件的数据溯源表中更新"来源日期"字段**
4. **本索引每周末自动维护（与RSS Cron对齐）**
