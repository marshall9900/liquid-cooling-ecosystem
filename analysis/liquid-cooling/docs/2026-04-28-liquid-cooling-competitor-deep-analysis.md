## 1.3 台资液冷企业集群（重点分析！）⭐⭐⭐⭐

台资企业是液冷ODM供应链的核心构成，尤其服务于Meta/Google/Amazon/Microsoft四大OTT的ODM代工体系。与大陆企业相比，台资企业在**精密制造工艺、全球ODM渠道、成本控制**方面具有显著优势。

### 1.3.1 奇鋐科技（AVC / Asia Vital Components）

| 维度 | 详情 | 可信度 |
|------|------|--------|
| 上市 | 台湾证券交易所 3017 | [已核实] |
| 总部 | 新北市 | [已核实] |
| 核心业务 | 散热模组（风冷+液冷）、风扇、机壳 | [已核实] |
| 2024年营收 | ~NT$650亿（约$20亿） | [估算] |
| 液冷业务 | CDU + Manifold + 冷板 + 液冷整柜 | [已核实] |
| 液冷营收 | ~NT$100-120亿（约$3-3.5亿/年） | [估算] |
| 客户 | Meta、Google、Amazon、Microsoft（ODM代工链） | [已核实] |

**产品线：**

| 产品 | 技术特点 | 市场定位 |
|------|---------|---------|
| 液冷CDU | 30-200kW，适合通用服务器液冷 | ODM配套为主，不做终端品牌 |
| Manifold | 机柜级分配，快速接头集成 | ODM整合方案组件 |
| GPU冷板 | 兼容NVIDIA HGX/DGX | ODM供应链深度绑定 |
| 3D Vapor Chamber | 均温板（高端） | 技术壁垒较高 |

**竞争优势：**
- **ODM代工深度绑定**：与广达、纬创、英业达、富士康等台湾ODM代工厂有20+年供应链合作
- **散热技术积累**：30年散热模组经验，风冷→液冷转型顺畅
- **成本控制能力**：台湾+大陆（昆山/东莞）制造基地
- **客户关系**：通过ODM间接服务全球四大OTT

**与海悟关系：**
- 竞争维度：**CDU + Manifold + 冷板**（三线竞争）
- 海悟优势：快接头（奇鋐不自研快接头）+ 中国大陆市场和政策优势（信创）
- 海悟劣势：ODM渠道为0，无法触及全球OTT代工链
- **战略判断**：台资企业在ODM供应链中有难以替代的位置，海悟应关注大陆市场自主品牌机会，不与台资在ODM渠道正面竞争
