## 二、冷板组件全景图（完整清单）

### 1.1 十大液冷冷板组件总览

| 组件类别 | 冷板应用场景 | 技术难点 | 市场成熟度 | 当前渗透率 | 决策权重最高方 |
|---------|------------|---------|-----------|-----------|--------------|
| **CPU冷板** | 服务器CPU散热 | 接触面平面度要求高 | 成熟 | ~60% | OEM厂家 |
| **GPU冷板** | AI训练/推理芯片 | 散热设计与GPU协同 | 成熟 | ~50% | GPU公司 |
| **存储冷板** | NVMe SSD/存储控制器 | 热插拔兼容、SSD托盘设计 | 发展中 | ~15% | OTT+OEM |
| **内存冷板** | HBM/DIMM/CAMM2 | 3D堆叠散热、热密度5-10x DIMM | 发展中 | ~10% | GPU公司 |
| **电源冷板** | PSU/800V架构 | 绝缘+密封+高压安全 | **新兴（蓝海）** | <5% | OEM+DC运营 |
| **通信模块冷板** | 光模块/交换机芯片 | 高速信号完整性、热密度低但数量大 | 发展中 | ~10% | OTT+OEM |
| **CDU冷板** | 冷却液分配单元 | 流量/压降/可靠性99.99% | 中等 | ~40% | **DC运营方** |
| **Manifold冷板** | 机柜歧管 | 标准化程度低、定制化需求 | 中等 | ~40% | **DC运营方** |
| **连接器/快接头冷板** | 液冷管路连接 | 零泄漏、快速拆装、耐压流阻 | 新兴 | ~30% | **DC运营方** |
| **TIM热界面材料** | 冷板与热源界面 | 材料科学、高导热+耐热循环 | 高壁垒 | ~60% | GPU公司 |

**还有哪些组件需要冷板？** 补充如下：
- **SSD散热支架**：针对2.5"/3.5"硬盘的专用液冷支架（非NVMe SSD）
- **主板供电模块冷板**：VRM/MOSFET散热
- **硬盘背板液冷**：企业级存储阵列的背板散热
- **光收发器（Transceiver）冷板**：可插拔光模块的端部散热

## 三、液冷决策链分析（四方博弈）

### 2.1 四方决策主体定位

```
┌──────────────────────────────────────────────────────────────┐
│                     液冷决策链四方                            │
├──────────────────────────────────────────────────────────────┤
│ OTT（最终需求方）                                             │
│   阿里/腾讯/字节/百度/GCP/Azure/AWS/华为云/天翼云             │
│   → 决定是否部署液冷、整体预算、选型认证                       │
├──────────────────────────────────────────────────────────────┤
│ GPU公司（技术标准执行方）                                      │
│   昇腾（华为）⭐强势：冷板规格必须通过昇腾认证                 │
│   阿里PPU ⭐强势：自研芯片，定标准                             │
│   寒武纪/海光/摩尔线程/燧原：相对弱势，受OTT/OEM影响大         │
│   NVIDIA/AMD：国际GPU，液冷方案成熟                            │
├──────────────────────────────────────────────────────────────┤
│ OEM厂家（系统集成+选型）                                       │
│   华为/浪潮/宁畅/华勤/超聚变/联想/ Dell/HPE                    │
│   → 有自己的标准，受OTT采购需求约束                            │
├──────────────────────────────────────────────────────────────┤
│ 数据中心运营方（自主采购决策）                                 │
│   IDC：世纪互联/宝信/万国/数据港等                             │
│   运营商：电信/移动/联通                                       │
│   → 对CDU/Manifold/连接器/快接头有独立决策权                   │
└──────────────────────────────────────────────────────────────┘
```

### 2.2 各组件决策链详述

#### 2.2.1 GPU芯片级冷板

**决策链**：OTT需求 → GPU公司定规格 → OEM适配 → DC运营验收

| 参与方 | 决策权重 | 决策内容 |
|--------|---------|---------|
| **GPU公司** | **40%** | 冷板尺寸/接口/散热参数规格书 |
| **OTT** | **30%** | 是否采用液冷方案、预算范围 |
| **OEM** | **20%** | 系统级散热设计、机械集成 |
| **DC运营** | **10%** | 机房改造可行性、维护便利性 |

**关键决策点**：GPU冷板规格书（华为昇腾/阿里PPU出具的认证标准）

**昇腾体系特殊性**：
- 昇腾950 PR/DT全系必须液冷，冷板规格必须符合华为标准
- 海悟必须进入昇腾供应链才能进入45-50%市场份额
- 昇腾认证周期：6-12个月

#### 2.2.2 电源冷板（PSU液冷）⭐ 蓝海

**决策链**：OEM主导 → DC运营采购 → OTT认可

| 参与方 | 决策权重 | 决策内容 |
|--------|---------|---------|
| **OEM** | **40%** | PSU选型、接口标准、功率定义 |
| **DC运营** | **30%** | 采购决策（自己的机房）、维护需求 |
| **OTT** | **20%** | 能效PUE要求、预算审批 |
| **GPU公司** | **10%** | 整机功耗预算约束PSU规格 |

**关键决策点**：PSU功率/接口标准（800V DC架构新标准）

**海悟机会**：DC运营方有独立采购权，OEM必须兼容——海悟可直接切入DC运营采购名单

#### 2.2.3 存储冷板

**决策链**：OTT需求 → OEM选型 → DC部署

| 参与方 | 决策权重 | 决策内容 |
|--------|---------|---------|
| **OTT** | **35%** | 存储容量/性能需求、SSD品牌指定 |
| **OEM** | **35%** | 存储方案选型、SSD冷板规格 |
| **DC运营** | **20%** | 部署位置、维护窗口 |
| **GPU公司** | **10%** | 存储与GPU互连的散热协同 |

**关键决策点**：SSD兼容性认证（与服务器系统的机械/散热兼容性）

#### 2.2.4 内存/HBM冷板

**决策链**：GPU规格 → OEM适配 → OTT验证

| 参与方 | 决策权重 | 决策内容 |
|--------|---------|---------|
| **GPU公司** | **45%** | HBM与GPU协同散热设计、内存规格 |
| **OEM** | **30%** | 主板设计、内存插槽布局 |
| **OTT** | **15%** | 验证HBM稳定性、对AI训练可靠性的影响 |
| **DC运营** | **10%** | 维护便利性（内存热插拔需求） |

**关键决策点**：HBM与GPU协同散热设计（芯片厂主导，OEM配合）

**海悟机会评估**：低——芯片厂主导（HBM与GPU一起设计），海悟进入门槛高

#### 2.2.5 通信模块冷板（光模块/交换机）

**决策链**：OTT网络规划 → OEM采购 → DC安装

| 参与方 | 决策权重 | 决策内容 |
|--------|---------|---------|
| **OTT** | **40%** | 网络架构、光模块数量/规格 |
| **OEM** | **30%** | 交换机选型、光模块采购 |
| **DC运营** | **20%** | 光纤布线、机房散热规划 |
| **GPU公司** | **10%** | InfiniBand/Ethernet网络拓扑影响散热需求 |

**关键决策点**：光模块热密度（Arista XPO等已建立液冷光模块标准）

**海悟机会评估**：中——光模块液冷已商业化（Arista XPO 100+合作伙伴），海悟可通过OEM合作进入

#### 2.2.6 CDU/Manifold ⭐⭐ 最高机会

**决策链**：DC运营自主决策 → OEM兼容要求 → OTT认可

| 参与方 | 决策权重 | 决策内容 |
|--------|---------|---------|
| **DC运营** | **45%** | CDU/Manifold选型、流量/接口标准、运维自主决策 |
| **OEM** | **25%** | 兼容CDU/Manifold的服务器设计 |
| **OTT** | **20%** | PUE要求（影响CDU能效） |
| **GPU公司** | **10%** | 整机散热设计对CDU参数的影响 |

**关键决策点**：CDU流量/接口标准、Manifold标准化程度（行业痛点）

**海悟机会评级**：⭐⭐⭐⭐⭐ 最高——DC运营方独立决策，海悟已有快接头+Manifold技术积累

#### 2.2.7 连接器/快接头 ⭐⭐ 最高机会

**决策链**：DC运营采购 → OEM标准兼容 → OTT认可

| 参与方 | 决策权重 | 决策内容 |
|--------|---------|---------|
| **DC运营** | **40%** | 采购决策（自己机房零泄漏是核心痛点） |
| **OEM** | **35%** | 快接头/连接器接口标准、认证 |
| **OTT** | **15%** | 液冷系统可靠性要求 |
| **GPU公司** | **10%** | 液冷系统完整性要求 |

**关键决策点**：快速拆装、零泄漏、标准化接口（类比USB在消费电子的作用）

**海悟机会评级**：⭐⭐⭐⭐⭐ 最高——快接头是海悟已有优势，横向扩展至液冷连接器天然契合
