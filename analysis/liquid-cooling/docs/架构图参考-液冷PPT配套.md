## 4. 液冷组件决策链（权力分布图）

```
GPU 芯片厂家
  ├─ NVIDIA: 定冷板标准 + 选OEM + 认证供应商 (最高权力)
  ├─ 华为昇腾: 封闭体系，定标准+认证 (封闭但可突破)
  ├─ 寒武纪: 开放生态，参考NVIDIA标准
  └─ 平头哥: 阿里体系，较开放
         │
         ▼ (标准→OEM适配)
服务器 OEM
  ├─ 浪潮/H3C: 执行GPU厂家标准，选择组件供应商
  ├─ 超聚变: 华为体系，使用华为认证供应商
  └─ 华勤: ODM模式，灵活但量小
         │
         ▼ (整机→DC部署)
OTT/IDC 运营方
  ├─ 字节/阿里: 对CDU/Manifold有自主决策权
  └─ 运营商DC: 直接采购CDU/Manifold
         │
         ▼
液冷组件供应商
  ├─ 冷板: CoolIT/AVC/英维克 → 海悟(待进入)
  ├─ CDU: Vertiv/Motivair → 海悟(远期)
  ├─ Manifold: nVent/Parker → 海悟(切入中)
  └─ 快接头: Staubli(垄断) → 海悟(P0国产替代)
```
