## 三定：定目标/策略/控制点

### 定目标(国内线)

```
2026    ¥50M    Manifold批量出货→H3C/浪潮/宁畅
2027    ¥300M   +电源冷板+内存冷板蓝海爆量
2028    ¥400M   +CPU冷板+快接头(认证通过)
2030    ¥1.0B   全组件+系统级(含CDU)+运维收入
```

### 定目标(海外线)

```
2026-27  ¥0      通过ODM间接出货(华勤等)
2028     ¥100M   OEM认证取得+海外DC项目
2030     ¥200M   自有海外渠道
```

### 定策略

| 策略 | 内容 |
|------|------|
| **进入策略** | Manifold先行(低门槛)→冷板跟进(认证后)→CDU+运维(远期) |
| **客户策略** | 先攻H3C+浪潮(快速出量)→借渠道进阿里/字节→申认证做NVIDIA/华为 |
| **竞争策略** | 不做CDU正面竞争、切蓝海组件、国内OEM渠道优势 |
| **海外策略** | ODM间接→认证直接、国内/海外双线独立 |
| **风险策略** | 10项监控指标、超阈即修正(见strategy/) |

### 定控制点

| 控制点 | 内容 | 时间 |
|--------|------|------|
| Intel UQD认证 | 冷板准入必备 | 2028H1前 |
| H3C供应商资格 | 出量基础 | 2026H2前 |
| 电源冷板研发 | 蓝海爆量前提 | 2026H2前 |
| 热性能测试台 | 研发验证能力 | 2026Q3前 |
