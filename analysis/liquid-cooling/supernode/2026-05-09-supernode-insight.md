## 一、超节点定义与分类

**超节点** = 多GPU通过高速互联集成为一个逻辑算力单元，通常以机柜级交付。

| 区分 | 说明 | 示例 |
|------|------|------|
| **产品名** | 市场名称 | NVL72 / Atlas 900 / 盘古 |
| **架构名** | 技术互联方案 | NVSwitch / HCCS / 自研互联 |
| **不等于** | 产品名≠架构名≠机柜型号 | NVL72用NVSwitch架构，但NVSwitch也可用于NVL36 |

## 二、NVIDIA系超节点

### 2.1 NVL72
| 字段 | 内容 |
|------|------|
| **产品名** | NVL72 (又名 GB200 NVL72) |
| **架构名** | NVSwitch 5.0 (NVLink 5) |
| **主导方** | NVIDIA |
| **代工方** | 鸿海(Foxconn)/广达(Quanta)/Dell/Supermicro |
| **GPU型号×数量** | GB200 ×72 (36颗 Grace+72颗 Blackwell GPU) |
| **互联协议** | NVLink 5 → 1.8TB/s per GPU → NVSwitch 5.0背板交换 |
| **单柜总功耗** | **~140-150kW** |
| **液冷设计** | |
| — 冷板 | GPU冷板×72 + CPU冷板(Grace)×36 = **108个冷板** |
| — 快接头 | 约720对（每GPU ~10对进出） |
| — CDU | 柜外CDU，30-40kW冷却能力×4-5台/柜 |
| — Manifold | **柜内大型Manifold** (2-4套)，72路流量分配 |
| — 冷却水温 | 进水~32°C / 出水~45°C (温水冷却) |
| — 供应商推测 | 冷板:CoolIT/Boyd/AVC | 快接头:Staubli/Parker | CDU:Vertiv/Motivair | Manifold:nVent |
| **状态** | 2025Q1已出货 |

## 三、华为昇腾系超节点

### 3.1 Atlas 900
| 字段 | 内容 |
|------|------|
| **产品名** | Atlas 900 |
| **架构名** | HCCS (Huawei Cache Coherence System) |
| **主导方** | 华为 |
| **代工方** | **超聚变(xFusion)** 为主 |
| **GPU型号×数量** | Ascend 910B ×数千 |
| **互联协议** | HCCS → 高速缓存一致性互联 (对标NVLink) |
| **单柜功耗** | **~50-70kW**(推测，基于400W×128+CPU+网络) |
| **液冷设计** | |
| — 冷板 | 华为自有冷板方案(Atlas液冷) |
| — 快接头 | 数量巨大(升腾集群) |
| — CDU | 华为自有CDU? 或认证供应商 |
| — 冷却水温 | 温水冷却 |
| **状态** | 已出货，国内超算中心+OTT部署 |
| **认证** | 🔥进入华为Atlas液冷认证体系才能供冷板 |

### 3.2 Atlas 下一代
- 随Ascend 910C/910D推出，可能基于SMIC N+3
- TDP提升→冷板升级需求
- 超聚变继续代工

## 七、海悟超节点切入机会

| 超节点 | 开放性 | 海悟机会 | 需要 |
|--------|--------|---------|------|
| **NVL72/NVL36** | NVIDIA指定供应商 | 长期(需NVIDIA认证) | NVIDIA Cold Plate认证 |
| **Atlas 900** | 华为认证 | 中期(需华为认证) | 进入华为认证体系 |
| **阿里PPU节点** | 阿里测试通过即可 | 🔥最优(国内、开放) | 通过阿里自有测试 |
| **字节节点** | 字节测试 | 🔥次优 | 通过字节/H3C测试 |
| **腾讯节点** | — | 探索 | — |
| Google/Amazon | 🔒封闭 | 无 | — |
| Meta/Microsoft | ⚠️半开放 | 远期(OCP认证) | OCP认证 |

> **结论**：国内OTT超节点（阿里/字节）是海悟最现实的超节点切入点，NVIDIA/华为需认证后才有机会，Google/Amazon封闭无需投入。
