## 核心结论

> **国产超节点是越来越重要的产业趋势**。国内头部厂商通过"服务器高密度集成+硬件级高速互联+高效液冷散热"协同设计，从"系统架构"层面突破，实现对海外算力的追赶。超节点趋势下或将带来国内液冷增量需求——液冷从可选配置升级为基础架构能力。

## 液冷供应链关键信息

### 1. 华为 Atlas 950 — 液冷设计亮点
- **分布式独立冷板**: 每一颗NPU均配置单独冷板 → 冷板需求 = GPU数量，精细化散热
- **机柜式CDU**: 不在机柜内部配置Rack级CDU，而是集中式CDU统一分配 → 提高维护便利性与系统一致性
- **EPDM软管**: 强调柔性与装配便利性
- **浮动接头**: 缓解装配公差、热膨胀及振动带来的机械应力 → 提升长期可靠性

### 2. 阿里 磐久128 — 液冷设计亮点
- **350kW供电/500kW散热** → 散热冗余设计
- **单GPU 2kW液冷散热能力** → 冷板散热密度标杆
- **6U高CDU** + 双柜液冷浮动盲插接头 + Manifold
- **快插接头**连接机柜级液冷管路
- NPO模块液冷保持低温 → 更高可靠性

### 3. 百度 天池 — 部署门槛最低
- 自研CDU天玑1.0 → 无需改造传统风冷机房即可直接部署
- **水、电、网三盲插**设计 → 普通运维人员可快速上架
- 降低液冷方案部署门槛 → 有利于液冷渗透率提升
- 千卡/4000卡未来规划 → 长期液冷增量

### 4. 腾讯 ETH-X — 开放生态
- ODCC开源项目，中国信通院+腾讯牵头
- **RoCE方案**（非英伟达NVLink私有协议）→ 降低成本与准入门槛
- 64卡规模可采用风冷 → 液冷非强制项
